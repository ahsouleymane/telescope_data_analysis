# Language purity of each community

One row per community.

- `purity`: share of the dominant language among channels with a known language.
- `entropy_bits`: Shannon entropy of the language mix (0 = single language).
- `effective_languages`: 2^entropy, the number of equally sized languages the community is equivalent to (1 = pure).
- `known_share`: share of the community's channels with a known language; low values make purity unreliable.

Generated by `code/language_analysis.py`.

## File
- `community_language_purity.csv` — 677 rows, 9 columns.
