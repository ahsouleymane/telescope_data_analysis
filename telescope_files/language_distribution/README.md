# Channels per language

Number of graph channels per language, over channels with a known language.

`share_of_known` is relative to channels with a known language, `share_of_all` to every channel of the graph (unknown included).

Generated by `code/language_analysis.py`.

## File
- `language_distribution.csv` — 48 rows, 6 columns.

## Columns
- `rank` (int64) — e.g. `1`
- `language` (str) — e.g. `ru`
- `language_name` (str) — e.g. `Russian`
- `n_channels` (int64) — e.g. `58817`
- `share_of_known` (float64) — e.g. `0.8494533585592351`
- `share_of_all` (float64) — e.g. `0.22520408006983902`
