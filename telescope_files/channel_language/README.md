# Channel -> language

One row per channel of the Channel-to-Channel graph.

- `language`: ISO-like language code; empty when unknown.
- `source`: `dataset` (Channel_Language.csv), `title` (langdetect on the channel title, only with `--enrich-titles`) or `unknown`.

Generated by `code/language_analysis.py`.

## File
- `channel_language.csv` — 261,172 rows, 3 columns.

## Columns
- `channel_id` (str) — e.g. `1375981076`
- `language` (str) — e.g. `ru`
- `source` (str) — e.g. `dataset`
