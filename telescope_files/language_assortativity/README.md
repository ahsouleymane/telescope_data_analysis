# Global language assortativity

One row. `assortativity_by_language` is Newman's attribute assortativity: 0 = language plays no role in who links to whom, 1 = every edge stays inside a language.

`share_of_edges_both_known` tells how much of the graph this is based on.

Generated by `code/language_analysis.py`.
