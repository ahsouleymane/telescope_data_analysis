# Agreement between language and community partitions

Computed on channels that have both a language and a community.

- `homogeneity`: 1 if every community holds a single language.
- `completeness`: 1 if every language falls entirely in one community.
- `nmi`, `ari`: symmetric agreement, 0 = independent, 1 = identical.

Generated by `code/language_analysis.py`.

## File
- `language_community_agreement.csv` — 1 rows, 8 columns.

## Columns
- `n_channels` (int64) — e.g. `69241`
- `n_languages` (int64) — e.g. `48`
- `n_communities` (int64) — e.g. `660`
- `nmi` (float64) — e.g. `0.3146011744894593`
- `ari` (float64) — e.g. `0.09198493041601322`
- `homogeneity` (float64) — e.g. `0.6699589201306847`
- `completeness` (float64) — e.g. `0.20556562686331162`
- `v_measure` (float64) — e.g. `0.3146011744894593`
