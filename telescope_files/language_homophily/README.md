# Homophily by language

For each source language: share of outgoing edges staying in the same language (`intra_share`), the share expected by chance, and their ratio.

Generated by `code/language_analysis.py`.

## File
- `language_homophily.csv` — 21 rows, 6 columns.

## Columns
- `language` (str) — e.g. `ru`
- `n_out_edges` (int64) — e.g. `1903064`
- `intra_share` (float64) — e.g. `0.9882473737089241`
- `expected_intra_share` (float64) — e.g. `0.9318552988743293`
- `homophily_ratio` (float64) — e.g. `1.0605159136860796`
- `language_name` (str) — e.g. `Russian`
