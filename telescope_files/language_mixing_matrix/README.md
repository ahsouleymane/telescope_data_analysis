# Language -> language edges

Directed edges (source channel -> destination channel) whose two ends have a known language. Languages outside the top 20 are grouped as `other`.

- `share_of_source`: share of the source language's outgoing edges.
- `expected_share`: share of the destination language among all edges (what random mixing would give).
- `ratio`: observed / expected; above 1 the link is more frequent than chance.

Generated by `code/language_analysis.py`.

## File
- `language_mixing_matrix.csv` — 239 rows, 8 columns.

## Columns
- `source_language` (str) — e.g. `ru`
- `dest_language` (str) — e.g. `ru`
- `n_edges` (int64) — e.g. `1880698`
- `share_of_source` (float64) — e.g. `0.9882473737089241`
- `expected_share` (float64) — e.g. `0.9318552988743293`
- `ratio` (float64) — e.g. `1.0605159136860796`
- `source_name` (str) — e.g. `Russian`
- `dest_name` (str) — e.g. `Russian`
